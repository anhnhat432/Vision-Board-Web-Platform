# Dear Our Future — Product Context

## Register

product

## Users

Gen Z Vietnamese users (18–28) who feel scattered about their future and want a calm, structured way to turn vague dreams into clear action. They use mobile first, prefer visual guidance over long explanations, and respond to warm, non-judgmental language.

## Product Purpose

Dear Our Future is a warm guided planning studio that helps users move from vague inspiration to visible, structured action through:

```text
Onboarding -> Life Balance -> Life Insight -> SMART Goal -> Feasibility Check -> 12-Week Plan -> Weekly Execution -> Reflection/Review
```

The core transformation:

```text
From vague inspiration to visible, structured action.
```

## Brand Personality

Warm, clear, short, guided, non-judgmental, encouraging.

Three-word personality: **Dreamy Guided Productivity**.

Emotional promise:

```text
You are not lost. You only need a clearer next step.
```

## Anti-references

- Corporate SaaS dashboards and admin panels
- Generic AI-generated app layouts
- Text-heavy planning tools and long surveys
- Dark mode as the default visual direction
- Neon, gaming, or financial aesthetics
- Purple-blue "AI gradient" patterns
- Stock wellness photos disconnected from user state
- Guilt-driven productivity copy

## Design Principles

1. **First meaningful result within 3 minutes** — show value before asking for deep setup.
2. **Visual first, text second** — every important screen needs a meaningful visual anchor tied to user state.
3. **One screen, one main action** — clear primary CTA, quieter secondary actions.
4. **Reduce cognitive load** — answer "What am I doing? Why does it matter? What next?"
5. **Progressive disclosure** — simple first, advanced later.
6. **Mobile-first for Gen Z** — single column, large tap targets, no horizontal scroll.
7. **Action over analysis** — every insight needs a concrete next step.
8. **Calm motivation, not pressure** — scoring guides adjustment, not shame.

## Accessibility & Inclusion

- Target WCAG 2.2 AA
- Respect `prefers-reduced-motion`
- Vietnamese-first typography: diacritic-safe line-height, no negative tracking on body, no clipped tone marks
- Touch targets ≥ 44px for primary controls
- Visible focus states and keyboard flow
- Do not rely on color alone for state
