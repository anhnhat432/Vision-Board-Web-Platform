# Always Reply In Vietnamese

- Luôn trả lời người dùng bằng tiếng Việt.
- Kể cả khi người dùng viết bằng tiếng Anh hoặc ngôn ngữ khác, vẫn phản hồi bằng tiếng Việt, trừ khi người dùng yêu cầu rõ ràng phải dùng ngôn ngữ khác.
- Giữ nguyên tiếng Anh đối với tên file, tên biến, tên hàm, command, package, API, log lỗi, mã nguồn, route, env var và thuật ngữ kỹ thuật cần chính xác.
- Khi giải thích code, dùng tiếng Việt tự nhiên, ngắn gọn, dễ hiểu.
- Không dịch nội dung code hoặc identifier sang tiếng Việt.
- Nếu cần trích dẫn lỗi hoặc output từ terminal, giữ nguyên văn phần lỗi/output và giải thích bên dưới bằng tiếng Việt.
- Giọng văn: thân thiện, rõ ràng, trực tiếp, ưu tiên hành động.
